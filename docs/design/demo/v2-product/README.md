# 于你 Yewne — Demo V2「真实结构版」

**信息架构 = 产品文档定义的主闭环｜视觉语言 = V1 已定稿的组件语言**

```
心事 → 三数 → 结果 → 深聊 → Aftercare → 记住这件事 → 心事地图
```

## 打开方式

V2 用了 ES module（`corpus.js`），**必须通过 http 打开**，不能双击文件。

```bash
cd demo && python3 -m http.server 5173
```

- V2：`http://localhost:5173/v2-product/`
- V1：`http://localhost:5173/v1-market/`

手机连同一 WiFi，把 `localhost` 换成内网 IP。

## 确定性引擎（`corpus.js`）

文档 §5.3 的算法，服务端确定性代码，大模型无权修改：

```js
r1 = (n1 - 1) % 6
r2 = (r1 + n2 - 1) % 6
r3 = (r2 + n3 - 1) % 6
```

内置自测（打开页面后看浏览器 console）：

- 4 条黄金用例（§5.4）：`1,1,1` / `2,5,2` / `6,6,6` / `3,3,3`
- 216 种合法输入穷举，全部得到三个有效宫位
- 越界输入 `7,1,1` / `0,2,3` / `2.5,3,4` 全部拒绝

解释文案不是硬编码 216 条断语，而是按 §5.8 的组合式方法生成：三宫允许含义 + 三位置规则 + 相邻转折关系。

## 六宫配色的刻意选择

文档 §4.6 要求「六宫使用六组可区分的色彩与几何符号，但**不把红色等同于凶、绿色等同于吉**」。

因此这里刻意把**绿色给了「赤口」（摩擦）**、**红色给了「小吉」（小进展）**，主动打断颜色与吉凶的语义映射。

| 宫位 | 色 | 符号 |
| --- | --- | --- |
| 大安 | 蓝 | 实心圆 |
| 留连 | 紫 | 同心环 |
| 速喜 | 橙 | 三角 |
| 赤口 | **绿** | 菱形 |
| 小吉 | **红** | 半圆 |
| 空亡 | 黄 | 空心方 |

## 文档合同的体现

- 三数结果由确定性代码算出，解释层不改变结果（§0.1）
- 结果页带 `method_version` / `corpus_version`，可追溯（§10.4）
- 结果页不给「会/不会」的确定答案，带不确定性说明（§5.10）
- 用户可跳过占问直接深聊，路径单独记录（§5.2、§9.1）
- Aftercare 核心内容不超过一屏，其余折叠（§6.4）
- 候选记忆默认全部未选中，逐条确认才写入（§6.6）
- 心事地图空状态说明「只有你选择记住的内容才会出现在这里」（§6.5）
- AI 标识在深聊与 Aftercare 持续可见（§8.10）
- 首页无「准确预测、改命、算准」类承诺（§10.10）
