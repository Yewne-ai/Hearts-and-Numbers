# 于你 Yewne — Demo V1「市场审美版」

**状态：定稿（2026-08-07）**

按产品提供的参考渲染图 1:1 还原，无自主设计成分。用于验证「中国市场审美」这层视觉语言。

## 打开方式

单文件、零依赖、零构建，双击 `index.html` 即可。

在手机上看（推荐，这才是真实观感）：

```bash
cd demo/v1-market && python3 -m http.server 5173
```

手机连同一 WiFi，访问 `http://<你的内网IP>:5173/`。

## 页面

| 页面 | 直达链接 | 说明 |
| --- | --- | --- |
| 于你（首页） | `#home` | 三张功能卡 + 大家正在聊 |
| 快速问问 | `#ask` | 问题输入 + 分类 + 大家常问 |
| 对话 | `#chat` | 小法师 + 气泡 + 状态选择 |
| 共鸣 | `#resonate` | 愿意被看见 + 同频话题网格 |

## 可交互

- 三张功能卡、大家正在聊三行 → 跳对应分页
- 底部 Tab 切换（于你 / 对话 / 共鸣）
- 「换一批」切换两批话题
- 情绪状态五选一、快速问问的分类六选一
- 「问这个」一键填入输入框、字数实时统计
- 返回箭头、hash 直达路由

「消息」「我的」参考图中无对应页面，保留图标与红点角标但不跳转。

## 技术说明

- 所有图形为内联 SVG（法师帽、双水滴、双心、状态表情、装饰气泡、Tab 图标、状态栏）
- 头像为 CSS 渐变 + 白色人形剪影，无外部图片依赖
- 桌面端套 iPhone 外框并自适应缩放；宽度 ≤500px 时切换为真机全屏（去外框、用系统状态栏、处理刘海与底部安全区）
